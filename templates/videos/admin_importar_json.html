Importar vídeos por JSON

Cole um JSON com vídeos do YouTube. A matéria e o conteúdo devem ser referenciados por slug.

Ver padrões

Formato esperado

Informe url ou youtube_id. Título e canal são obtidos automaticamente do YouTube; campos como titulo ou canal_nome no JSON são ignorados. Máximo de 50 vídeos por importação. 

{
  "materia": "matematica",
  "videos": [
    {
      "conteudo": "porcentagem",
      "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
      "nota_curador": "Assista antes de resolver as questões de porcentagem.",
      "ordem": 1,
      "ativo": true
    }
  ]
}
